# Evidence status

Every recipe is unvalidated on current inputs, not evidence that the input will
produce the intended effect. No prior project's media or approval transfers
to another user. Keep take-specific results with the current production,
not in this reusable skill.

## Current-input checks

- Check the supplied photo or clip against the recipe's input contract.
- Verify the destination's current reference-role and parameter support before
  any separately authorized generation. Preserve documented unsupported flags;
  unknown support is not permission to submit.
- Compare the returned take with the recipe's QA list. Record how it was
  inspected and unresolved defects, not just a pass label.
- Check exact counts, wardrobe continuity, timing, unwanted lettering and
  unwanted audio. For whole-clip restyles, check every intended region.
- Validate post-dependent mechanics in the completed composite, not the
  generated clip alone.
- Recheck higher-resolution renders, reference changes and chained clips;
  approval of an earlier take is not approval of a new output.

Check each recipe's intended style coverage, including subject and foreground.
Offer an alternative when the current output misses the requested mechanic,
without presenting another recipe as validated on current inputs.
This guidance does not trigger generation or automatic prompt review in the
prompt-only workspace.
